# is6400-business-data-analytics

IS6400课程小组项目的代码仓库，探索数据分析在商业领域的应用。

数据集来源：[Car Price Prediction Challenge](https://www.kaggle.com/datasets/deepcontractor/car-price-prediction-challenge)

**_我们有8个品牌方_**

**1. 多元线性回归板块**

- 我们可以对于每一个品牌都进行多元线性回归（总体，变量筛选，降维都来试试），然后对每个品牌的属性的数值进行检验，品牌之间比较，康康哪个属性最重要

- 我们也可以对全体8个品牌一起进行多元线性回归，得到一个基准值，康康各个品牌和基准值之间的差异

**2. 时间序列分析**

- 我们是有汽车品牌价格和时间两个数据的，我们可以进行一些时间序列分析（但是感觉做的不是很出来？？？）

**3. 树状图分析**

- 树状图能够更加良好的预测分类问题，可以和聚类分析一起运作，比如分4个类，然后使用树状图来预测这个属于哪个类，每个类有一些不同的特点，未来造车我们就可以依据这些特点来进行价格设置和类型安排。

**4. 人工神经网络**

- 这种多维的数据建议使用人工神经网络
